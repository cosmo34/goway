Support

Last updated: September 4, 2026

Need help with GOWAY? Here’s how to contact us and fix common issues.

Contact

Email: support@goway.app
GitHub Issues: github.com/cosmo34/goway/issues

What the app covers

GOWAY provides real-time schedules, trip planning and navigation for the TaM network (Montpellier). Transit data comes from TaM open data.

Common issues

  • No schedules: check connectivity and that the production API is reachable.
  • Location: allow While Using (or Always) in Settings → GOWAY.
  • Live Activity / notifications: enable in iOS Settings; available on production builds.
  • Wrong itinerary: report the route, time and stops involved.
