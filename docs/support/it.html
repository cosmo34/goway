Serve aiuto con GOWAY? Ecco come contattarci e risolvere i problemi più comuni.

Contatto

GitHub Issues: github.com/cosmo34/goway/issues

Copertura

GOWAY offre orari in tempo reale, itinerari e navigazione per la rete TaM (Montpellier).

Problemi comuni

  • Nessun orario: verifica connessione e API di produzione.
  • Posizione: autorizza in Impostazioni → GOWAY.
  • Live Activity / notifiche: abilita su iOS (build production).
  • Itinerario errato: indica percorso, orario e fermate.
