Cobertura

GOWAY ofrece horarios en tiempo real, itinerarios y navegación para la red TaM (Montpellier).

Problemas frecuentes

  • Sin horarios: comprueba la conexión y la API de producción.
  • Ubicación: autorízala en Ajustes → GOWAY.
  • Live Activity / notificaciones: actívalas en iOS (build de producción).
  • Itinerario incorrecto: indica ruta, hora y paradas.
