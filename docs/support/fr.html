Que couvre l’app ?

GOWAY fournit horaires temps réel, itinéraires et navigation pour le réseau TaM (Montpellier). Les données transport proviennent de l’open data TaM.

Problèmes fréquents

  • Pas d’horaires : vérifiez la connexion et que l’API de production est joignable.
  • Localisation : autorisez « Lorsque l’app est active » (ou toujours) dans Réglages → GOWAY.
  • Live Activity / notifications : activez-les dans Réglages iOS ; disponibles sur build production.
  • Itinéraire incorrect : signalez le trajet, l’heure et les arrêts concernés.
